# Customer Churn Analysis - Python & Pandas

# Overview
Exploratory data analysis on 10,000 bank customer records
to identify churn patterns across demographics, geography,
balance, and product usage.

# Tools Used
- Python (pandas)
- Google Colab

## Key Findings
- Overall churn rate: 20.37%
- Female customers churn at a higher rate than male customers
- Customers aged 51–60 show the highest churn
- Germany records the highest churn by geography
- Churned customers hold higher average balances than retained ones
- Customers with 3–4 products show notably different churn behaviour

## Analysis Performed
- Overall churn rate calculation
- Churn rate by gender, age group, and country
- Average balance: churned vs retained customers
- Credit score range vs churn
- Age group binning using pd.cut()
- Average age and product churn analysis

## Dataset
Source: Kaggle - Churn Modelling Dataset
Records: 10,000 | Features: 14 columns
